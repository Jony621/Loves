# For My Love — Romantic Website

A responsive pink-themed romantic website with a clickable heart, a step-by-step love story, and looping background music.

## Run it
1. Extract `for_my_love_website.zip`.
2. Place a legally obtained copy of **Prithibir Joto Sukh** in the same folder as `index.html`.
3. Name the audio file exactly `prithibir-joto-sukh.mp3`.
4. Open `index.html` in a modern browser.
5. Click the heart. The song starts on that first click and loops throughout the story.

## Browser autoplay note
Browsers generally block audio from playing with sound before a user interacts with the page. The music therefore starts when the visitor clicks the opening heart, then continues in the background as they move through the story.

## Customize
- Edit the messages and headings in `script.js` inside the `story` array.
- Change colors, fonts, spacing, and animations in `style.css`.
- The site is static and needs no installation or server.

Note: Browser click interactions use JavaScript (not Java). Java is typically used for a backend; it is not run directly in a standard browser page.
